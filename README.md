## Three ways I create value

### Bioinformatics and cloud engineering
- Python, Docker and Nextflow pipelines for DNA data processing and analysis on AWS
- Moved Step Functions applications onto Nextflow workflows running on AWS Batch
- Variant annotation services on AWS built with CDK
- GitLab CI/CD and GitHub Actions that automate testing, validation and releases
- Verification and validation documentation, so clinical software ships with its evidence

### AI and agentic systems
- RAG chatbot for static sites (Pinecone vector store, deployed on Render)
- Chrome extensions that bring several LLM providers into job-search and prompt-engineering workflows
- LangChain, CrewAI and Ollama, plus daily use of Copilot and Claude in engineering work
- Machine learning on large biological datasets: regression, neural networks, clustering, NER and SVM

### Solutions and pre-sales for health tech
- Solutions architect at MediSapiens: customer use cases turned into technical specifications
- Scientific and system expert on sales calls, with mock-ups and demos for prospects
- Projects led from inception to launch, customer training, and an international developer team serving Europe and the USA
